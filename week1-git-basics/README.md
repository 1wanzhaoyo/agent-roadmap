# W1 · Git 工作流 + 项目结构（10.12–10.18）

## 任务

1. 解决 GitHub 推送凭据（gh CLI 或 PAT），建 public 仓库并首次 push
2. 把课设代码整理成规范结构（README / requirements.txt / .gitignore，排除数据大文件）
3. 练一次分支 → 改 README → PR → 合并
4. 写本仓库 README（7 周路线 + 环境要求）
5. 读微软课程 Lesson 01，写 5 条笔记

## 验收标准

GitHub 上有 2 个规范仓库，陌生人按 README 能跑起来；能讲清 Agent = LLM + 上下文 + 工具
